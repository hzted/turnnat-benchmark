Overview

Benchmark Summary

TurnNat studies automatic evaluation of turn-taking naturalness in two-channel spoken dialogue. Each benchmark item contains a natural dialogue clip and a matched perturbed version, where the perturbation changes conversational timing while preserving speaker identity, lexical content, and recording conditions as much as possible.

The released resources will include code, perturbation manifests, analysis scripts, and a small set of demo audio examples. Full data access will depend on the redistribution terms of the underlying speech data.

Perturbation Benchmark

Turn-Taking Perturbation Types

The benchmark targets timing errors that are common in spoken interaction but difficult to capture using content-only metrics.

Late Response

Delays a responding utterance, creating an abnormally long response gap.

Early Entry

Advances a response, creating premature overlap with the current speaker.

Hold Instead of Shift

Removes a responding turn so the current speaker appears to retain the floor.

Shift Instead of Hold

Inserts a response where the same speaker would normally continue.

Excessive Backchanneling

Adds extra listener feedback in regions where the listener is originally silent.
